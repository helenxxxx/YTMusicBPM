Connect YouTube Music

There's no official YouTube Music API, so Cadence borrows your signed-in browser session. It takes a minute:

  1. Open music.youtube.com in Chrome or Firefox and make sure you're signed in.
  2. Open developer tools (F12, or ⌘⌥I on a Mac) and choose the Network tab.
  3. Type browse in the filter box, then click Library on the YouTube Music page.
  4. Right-click the browse?… request that appears. Chrome: Copy → Copy request headers. Firefox: Copy Value → Copy Request Headers.
  5. Paste it below.
